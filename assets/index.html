Mode —

At startup the robot does not move. All 15 servo IDs, the IMU and the saved calibration must be ready for 0.5 s, then press X on the board gamepad (or click Default pose here) to enable torque into the default pose — it never stands up on its own. It then holds without a browser or controller until A starts walking or B / Torque off stops it. A stop or sensor failure cancels the pose, but X can be pressed again as soon as readiness returns — no app restart needed. In manually selected modes, a missing ID is shown here and does not block the others. Default pose and walk send position targets. While this page controls motion, closing it or leaving it in the background for more than 1 second turns position control off. Board Bluetooth control uses its own heartbeat and continues after the updated page closes. Pick runs only while walking upright: it plays xgoduck_pick for one 4 s cycle, then returns to walk. Roulade plays xgoduck_roulade for 1.9 s with twist and head at 0, and leg/neck smoothing at 0.15, then returns to walk and the previous smoothing. Tilt does not select get-up during those 1.9 s.

Walk: tilt above 55° for 0.15 s selects the get-up model, holds action = 0 for 1 s, then runs the get-up action. Get-up: tilt below 15° for 1 s returns to walk. Twist and head commands are zero during get-up. Inference-only mode previews the switch without enabling torque. During pick the command is a phase encoding; the mouth opens to 30° and closes when φ ≥ 0.4.

Xbox / GameSir controller

Gamepad disabled

Connect the controller to the computer running this browser, in PC / XInput mode. Release LB and center both sticks, then hold LB: left stick moves forward/back and sideways; right stick turns. Release LB to zero motion. B turns torque off. Select Walk / get up above to enable walking. Gamepad takes priority over keyboard and screen pads while enabled.

Use HTTPS or http://localhost (SSH port forwarding) for browser gamepad access. See README → Xbox / GameSir gamepad.

Board Bluetooth controller

Board Bluetooth: waiting for host reader.

For a controller paired directly to UNO Q, run tools/board-gamepad.py on the board host. Press X for the default pose, then release LB, center sticks and press A to start walking; hold LB to move. B turns torque off. Closing this page leaves board gamepad control active; Torque off always stops it.

Head and mouth

Head 1–4 are radians (±1). The mouth is motor 34, 0–30°, and is sent with the 50 ms command heartbeat. It is not part of the policy observation.
